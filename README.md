# LeadDesk Mini

A full-stack lead management application built for the
Digital Heroes Full Stack Development Training Task.

## Features

- Public lead capture form
- Client-side validation
- Server-side validation
- MongoDB database
- Admin authentication
- Protected admin dashboard
- Lead search
- Lead status management
- Responsive UI

## Lead Status

- New
- Contacted
- Closed

## Tech Stack

Frontend:
React, Vite, Axios, React Router

Backend:
Node.js, Express.js

Database:
MongoDB Atlas

Authentication:
JWT

Deployment:
Vercel + Render
